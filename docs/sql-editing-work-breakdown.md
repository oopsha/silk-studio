# SQL 편집 경험 — 작업 배분

로드맵 4번 항목을 한 번에 처리하기엔 범위가 크므로, **요청 5번**으로 나눈다.  
각 요청은 한 채팅에서 end-to-end로 끝낼 수 있는 단위다.

## 현재 상태 (기준)

- Monaco 에디터 + 문장/선택 실행·취소(4-A), 방언별 하이라이트·포맷(4-B), 키워드·스키마 자동완성(4-C), 실행 히스토리·즐겨찾기(4-D), 실행 계획·오류 마커(4-E)까지 반영
- 로드맵 4번 SQL 편집 기능은 배분 항목 기준으로 완료 (검증은 앱에서 확인)

---

## 4-A. 문장/선택 실행 + 실행 취소

**상태:** 구현 완료 (검증은 앱에서 확인)

**의존성:** 없음 (가장 먼저)

### 범위

- 선택 영역만 실행
- 선택이 없으면 커서 위치의 한 문장(세미콜론 기준) 실행
- 실행 중 취소 (agent/`Statement` cancel 또는 요청 중단)
- 단축키: 기존 `Ctrl+Enter`를 “현재 문장/선택 실행”으로 정리  
  (필요 시 “전체 실행”은 별도 커맨드)

### 완료 기준

- 여러 문장이 있는 탭에서 커서/선택만 실행됨
- 실행 중 Cancel로 멈춤
- Oracle/MySQL에서 회귀 확인

### 요청 문구 예

> SQL 문장/선택 실행과 실행 취소를 end-to-end로 구현해줘. 선택이 있으면 선택만, 없으면 커서의 현재 문장을 실행하고, 실행 중 취소를 지원해줘.

---

## 4-B. SQL 문법 강조 + 포맷

**상태:** 구현 완료 (검증은 앱에서 확인)

**의존성:** 4-A와 독립 가능하지만, A 다음이 자연스러움

### 범위

- 드라이버/방언별 SQL language 등록 (Oracle / SQL Server / MySQL·MariaDB / PostgreSQL)
- Format Document / Format Selection (`sql-formatter` 등)
- Editor 설정(indent 등)과 연동

### 완료 기준

- `.sql`/쿼리 탭에서 방언별 하이라이트
- 포맷 커맨드/단축키 동작

### 요청 문구 예

> SQL 방언별 문법 강조와 포맷(문서/선택)을 구현해줘. 연결 드라이버에 맞춰 방언을 고르고, Editor 설정을 반영해줘.

---

## 4-C. 자동완성 (키워드 + 스키마 객체)

**상태:** 구현 완료 (검증은 앱에서 확인)

**의존성:** 메타데이터 트리(이미 있음) 활용 → 4-A/B 이후 권장

### 범위

- SQL 키워드/함수 자동완성
- 연결된 DB의 schema/table/column 후보  
  (기존 `connection.metadata` 확장 필요할 수 있음 — column 목록)
- 트리거 문자 `.` 및 `Ctrl+Space`

### 완료 기준

- `SELECT * FROM ` 뒤에 테이블 후보
- `schema.` / `table.` 뒤 객체/컬럼 후보
- 연결 없을 때는 키워드만이라도 동작

### 요청 문구 예

> SQL 자동완성을 구현해줘. 키워드와 현재 연결의 스키마/테이블/컬럼을 제안하고, 연결이 없으면 키워드만 제안해줘.

---

## 4-D. 실행 히스토리 + 즐겨찾기

**상태:** 구현 완료 (검증은 앱에서 확인)

**의존성:** 4-A (실행 단위가 정리된 뒤)

### 범위

- 성공/실패 실행 기록 저장 (SQL, 시각, 소요시간, 연결)
- 히스토리 패널/뷰에서 재실행·에디터로 넣기
- 즐겨찾기 저장/이름 지정/재사용
- localStorage 또는 앱 설정 저장 (비밀번호/시크릿 제외)

### 완료 기준

- 실행 후 히스토리에 쌓임
- 즐겨찾기 추가/삭제/재실행

### 요청 문구 예

> SQL 실행 히스토리와 즐겨찾기를 구현해줘. 재실행·에디터 삽입·로컬 저장까지 end-to-end로 해줘.

---

## 4-E. 실행 계획 + 오류 위치

**상태:** 구현 완료 (검증은 앱에서 확인)

**의존성:** 4-A, 가능하면 4-B (에디터 마커)

### 범위

- Explain / Explain Plan 커맨드 (드라이버별 SQL)
  - Oracle: `EXPLAIN PLAN FOR` → `DBMS_XPLAN.DISPLAY()`
  - MySQL / MariaDB: `EXPLAIN`
  - PostgreSQL: `EXPLAIN (FORMAT TEXT)`
  - SQL Server: `SET SHOWPLAN_ALL ON` → 문장 → `OFF` (finally 복구)
- 결과를 패널에 표시 (`silk.query.explain`, `Ctrl+Shift+E`)
- JDBC 오류의 오프셋/라인/컬럼을 Monaco 마커·스크롤로 표시 (`silk.sql` owner)

### 완료 기준

- Explain 실행 결과가 패널에 보임
- 구문 오류 시 에디터에 위치 표시  
  (드라이버가 위치 정보를 줄 때만; 없으면 실행한 문장/선택 범위)

### 요청 문구 예

> SQL 실행 계획(Explain)과 오류 위치 표시를 구현해줘. 드라이버별 Explain을 지원하고, 가능하면 오류를 Monaco 마커로 표시해줘.

```
 → 4-D 히스토리·즐겨찾기
 → 4-E 실행 계획·오류 위치  ✅
```
